# Runbook

## Mac One-Click Files

For teammates on Mac, use:

```text
scripts/mac/Install Content Calendar.command
scripts/mac/Start Content Calendar.command
scripts/mac/Update Content Calendar.command
```

`Install` clones or updates the GitHub repository into `~/Documents/content-calendar-studio`, installs packages, prepares `.env`, creates the local database, seeds starter data, starts the app, and opens `http://localhost:3000`.

`Start` runs an already installed app.

`Update` pulls the latest code from GitHub, runs `npm install`, and updates the local database schema.

## Manual Start The App

```bash
cd "Content Calendar Helper"
cp .env.example .env
npm install
npm run db:push
npm run db:seed
npm run dev
```

Open:

`http://localhost:3000`

## Local Database

The local SQLite database is created at:

`prisma/dev.db`

It is generated by:

```bash
npm run db:push
```

Seed demo data with:

```bash
npm run db:seed
```

## Environment Variables

Required:

```env
DATABASE_URL="file:./dev.db"
```

Optional text providers:

```env
OPENAI_API_KEY="..."
ANTHROPIC_API_KEY="..."
```

Optional image provider:

```env
OPENAI_API_KEY="..."
```

OpenAI image generation only runs if the app setting is switched to OpenAI.

## Team Development

For local development, each teammate should use their own `.env` and local SQLite database. Do not commit `.env`, `prisma/dev.db`, generated images, or local logs.

For shared editing in one browser-accessible workspace, use the deployment plan in `docs/TEAM_ACCESS_AND_DEPLOYMENT.md`.

## Local Text Generation

Ollama is optional if cloud text providers are used.

Install Ollama from:

`https://docs.ollama.com/macos`

Then run:

```bash
ollama serve
ollama pull llama3.1:8b
```

## Local Image Generation

The app expects a local Stable Diffusion-compatible endpoint by default:

```text
http://127.0.0.1:7861/sdapi/v1/img2img
```

Run the local generator with API enabled, then set the image model/checkpoint name in the app settings. Automatic1111-style `txt2img` endpoints are also supported if you switch the endpoint URL.

The default local generator is a draft renderer. For final social assets, use the production brief in the post workspace and paste that brief into ChatGPT, Nano Banana, or a production ComfyUI workflow with FLUX/SDXL. Add typography outside the image model for cleaner text.
